SYSTEM ARCHITECTURE

Core Engineering Standards

TENET 01 // FOCUS

Spacebar-Safe Injection

Traverses single-child DOM wrappers to dock natively beside Fullscreen. Calls btn.blur() after activation so Spacebar always controls play/pause.

TENET 02 // SUBTITLES

Zero-Delay Dialogue Shield

Toggles .player-timedtext opacity simultaneously with video blurring to protect against dialogue plot spoilers.

TENET 03 // ENCLAVE

100% Local Execution

Zero analytics, zero remote telemetry, zero external network calls. All state is held locally in Chrome's sandboxed storage.
